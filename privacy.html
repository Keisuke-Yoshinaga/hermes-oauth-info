プライバシーポリシー / Privacy Policy

最終更新日 / Last updated: 2026-10-05

対象 / Scope

Hermes Personal Assistant（以下「本アプリ」）は、開発者本人のみが利用する個人用アプリです。

Hermes Personal Assistant ("the App") is a personal application used only by its developer.

取得する情報 / Data accessed

本アプリは、利用者本人が許可した範囲で、Google カレンダー、Google ドライブ等の本人のデータにアクセスします。

The App accesses the user's own Google data (such as Google Calendar and Google Drive) only within the scopes the user has explicitly granted.

利用目的 / Use of data

取得したデータは、本人の予定・記録の整理、要約、リマインドのためにのみ、本人の端末上で使用します。広告・販売・プロファイリング等には使用しません。

Data is used only on the user's own device to organize, summarize and remind the user of their own schedule and records. It is never used for advertising, sale or profiling.

第三者提供 / Sharing

取得したデータを第三者に販売・提供することはありません。

Data is not sold or shared with third parties.

Google API Services User Data Policy

本アプリによる Google API から取得した情報の使用および他アプリへの転送は、Limited Use 要件を含む Google API Services User Data Policy に準拠します。

The App's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

保存と削除 / Retention and deletion

認証情報および取得データは本人の端末上にのみ保存されます。アクセスは Google アカウントの「サードパーティ製のアプリとサービス」（https://myaccount.google.com/connections）からいつでも取り消せます。

Credentials and data are stored only on the user's own device. Access can be revoked at any time at https://myaccount.google.com/connections.

お問い合わせ / Contact

本アプリの OAuth 同意画面に表示されるサポートメールアドレスまでご連絡ください。

Please contact the support email address shown on the App's OAuth consent screen.
